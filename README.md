# МПГУ ИМИ Шаблон курсовой работы
Репозиторий исходного кода на языке $\mathrm{\LaTeX}$, содержащий шаблон курсовой работы.

В шаблоне представлены примеры:
- текстов введения и заключения;
- списка литературы;
- оглавления;
- нумерованных и маркированных списков;
- математических формул;
- схем, построенных с помощью TikZ;
- рисунков, импортированных с помощью файлов `.jpg`, `.png` и `.pdf`;
- таблиц;
- нумерованных определений и теорем;
- круговых и столбчатых диаграмм;
- листингов кода;
- перекрёстных ссылок.
